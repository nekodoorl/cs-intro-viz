# 第一次提交与 PR 操作卡（发给每位队友）

> 目标：**每人**独立完成一次「改文件 → 提交 → 推送 → 发起 PR」，
> 这样仓库里才会留下分支记录、commit 记录和 PR 记录（占评分 30%）。

---

## 0. 一次性准备（每人只做一次）

打开 PowerShell（Win 键搜 `PowerShell`），执行：

```powershell
git config --global user.name "你的名字"
git config --global user.email "你的GitHub注册邮箱"
```

验证：

```powershell
git config --global --list
```

---

## 1. 把仓库克隆到本地

```powershell
cd D:\
git clone https://github.com/组长用户名/cs-intro-viz.git
cd cs-intro-viz
```

> 如果提示 `Repository not found`：说明组长还没把你加成协作者，或者用户名拼错了。

---

## 2. 建一个自己的分支

**永远不要直接在 main 上改。**

```powershell
git checkout -b docs/你的名字
```

检查当前分支（前面带 `*` 的就是你所在的分支）：

```powershell
git branch
```

---

## 3. 改一个文件

用记事本或 VS Code 打开 `README.md`，在「团队分工」表格里找到自己那一行，把信息补全：

```markdown
| 成员B | 2026xxxx | 核心算法 core/converter.py | @member-b |
```

保存。

---

## 4. 提交并推送

```powershell
git status                                        # 看看改了哪些文件（红色是未提交）
git add README.md                                 # 把改动放进待提交区
git commit -m "docs: 补充 成员B 的分工信息"        # 打个存档点
git push -u origin docs/你的名字                   # 推到远程
```

推送成功后，终端会打印一行类似：

```
remote: Create a pull request for 'docs/你的名字' on GitHub by visiting:
remote:      https://github.com/组长用户名/cs-intro-viz/pull/new/docs/你的名字
```

复制这个链接。

---

## 5. 发起 Pull Request

1. 浏览器打开上面那个链接
2. 标题填：`docs: 补充 成员B 的分工信息`
3. 描述里写一句：`已完成分工表填写，请组长审核`
4. 点绿色 **`Create pull request`**

到这里你的任务完成，等组长合并。

---

## 6. 组长收到 PR 后

1. 打开 PR 页面 → `Files changed` 看一眼改动
2. 点 `Review changes` → `Approve` → `Submit review`（这一步就是 Code Review）
3. 点 `Merge pull request` → `Confirm merge`
4. 本地同步：

```powershell
git checkout main
git pull
```

---

## 常见问题

| 报错 | 原因 | 解决 |
|---|---|---|
| `Repository not found` | 没被加成协作者 | 联系组长加人 |
| `Authentication failed` | 密码框填了登录密码 | 改用 Personal Access Token |
| `Updates were rejected` | 远程有别人的新提交 | 先 `git pull` 再 push |
| `nothing to commit` | 文件没保存 / 改的不是被跟踪文件 | 检查是否保存、`git status` 看状态 |
| `fatal: not a git repository` | 不在项目文件夹里 | `cd` 到 `cs-intro-viz` 目录 |
